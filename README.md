# portfolio

Personal portfolio — Venukiran Sankar, AI &amp; Python engineer.

**Live:** https://venukiran004.github.io/portfolio

## About the build

A single self-contained `index.html`. No build step, no dependencies, no
external requests — all CSS, JavaScript and graphics are inline, and every
diagram is hand-authored SVG.

- Light and dark themes, following the visitor's system setting
- Interactive node-network hero rendered on canvas
- Bento layouts with cursor-tracked spotlights and 3D tilt
- Fully honours `prefers-reduced-motion`

## Editing

Open `index.html` and edit directly. Pushing to `main` redeploys the site.
